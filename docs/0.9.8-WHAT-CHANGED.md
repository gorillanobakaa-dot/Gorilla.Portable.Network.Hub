# 0.9.8, in plain language

**One fewer thing to type — because somebody actually checked.**

---

## What changed

0.9.7 told you to run three lines to fix a Windows laptop whose hotspot would
not switch on. It is two.

The third one was **Wi-Fi Direct Services Connection Manager**
(`WFDSConMgrSvc`). It was in the list for a sensible-sounding reason: Windows 11
builds its hotspot on something called Wi-Fi Direct, so the thing that manages
Wi-Fi Direct connections looks like it must be part of it.

That was a guess. A good one, and wrong.

## How it was settled

By trying it, on a real laptop, with that service **deliberately left switched
off**.

The hotspot worked anyway. Not "looked like it might work" — it actually turned
on, and Windows created the extra network adapter it creates when a hotspot is
genuinely running.

So the line came out.

## Why bother, for one line

Because of what happens to the **next** person.

If you tell somebody to change three things and two of them were the problem,
they have now changed something on their laptop that did not need changing —
and nobody can tell afterwards which change actually fixed it. Not them, not
whoever looks at that machine next, not us.

One line less to type is the small part. Not touching something that did not
need touching is the real one.

## So the fix is now

```powershell
Set-Service icssvc -StartupType Manual
Set-Service SharedAccess -StartupType Manual
Start-Service icssvc
```

That is the whole thing. `hub doctor` prints it for you, and only if your
laptop actually has the problem.

## And it is all measured now, not reasoned

The advice 0.9.7 shipped was honest about being an argument rather than a
measurement. It is a measurement now, three times over:

| | what Windows did |
|---|---|
| **Before** | could not even build the thing that fills in the hotspot boxes |
| **After the two lines** | name, password and band appeared; hotspot switched **on** |
| **Put back as it was** | the same failure returned |

That last row is the important one. Undo the change and the fault comes back —
which is how you know it was the cause and not a coincidence.

One more thing that came out of it: **Internet Connection Sharing never
actually runs.** It only has to be *allowed* to run. So there is nothing else
to do after those three lines, and nothing left running on your machine that
was not running before.

---

## Does this change anything on Linux?

**No.** Nothing in it exists there. Linux users should stay on **0.9.5**.
