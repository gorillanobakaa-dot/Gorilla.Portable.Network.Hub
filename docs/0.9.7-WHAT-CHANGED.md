# 0.9.7, in plain language

**The laptop is not broken. Somebody switched part of it off.**

---

## What happens

You try to hand files out over wifi. The program tells you to switch the
hotspot on yourself first, in Windows Settings. You go there, press the switch,
and Windows says:

> **We can't set up mobile hotspot.**

Underneath, the boxes for Name, Password and Band are not wrong. They are
**empty**. Nothing on that screen says why, and nothing on it mentions a
service — so there is nothing to look up, nothing to search for, and no thread
to pull.

At that point almost anybody concludes the laptop is too old, or the wifi card
is broken, or this program does not work. All three are wrong.

## What is actually wrong

Two pieces of Windows have been **switched off**:

- **Windows Mobile Hotspot Service** (`icssvc`)
- **Internet Connection Sharing** (`SharedAccess`)

That is it. The wifi card is fine. On the laptop this was found on, it was
connected to a network at 173 megabits a second the whole time.

### Why they were off

Second-hand laptops have usually been "speeded up" by somebody. Nearly every
list on the internet that promises to make Windows faster turns these two off,
because almost nobody shares a network connection and they look like free
memory.

On this machine, **150 services** had been switched off that way. Those two
were among them.

This is not unusual, and it is not somebody's mistake. It is the ordinary state
of a laptop that has had a previous owner — which is the only kind of laptop
the rooms this tool is built for have.

## What the program does now

Run `hub doctor` and, **only if something really is switched off**, it now
tells you:

```
This laptop cannot make a wifi network, and it is not the wifi card.

Parts of Windows have been switched off on this machine. This is very
common on a second-hand laptop: the lists that promise to speed Windows
up nearly all switch these off, because almost nobody shares a network
connection. Windows does not tell you that is why. It says it cannot set
up a mobile hotspot and leaves the box empty, so the laptop looks broken
when it is only switched off.

Switched off here:
  Windows Mobile Hotspot Service  (icssvc)
  Internet Connection Sharing  (SharedAccess)

To switch them back on, open Windows Terminal or PowerShell AS
ADMINISTRATOR. Right-click the Start button, and choose the entry with
(Admin) after it. Then type these lines, one at a time:

  Set-Service icssvc -StartupType Manual
  Set-Service SharedAccess -StartupType Manual
  Start-Service icssvc

Then open Settings, Network and internet, Mobile hotspot. The boxes
for name and password should now be filled in instead of blank.

If it asks for an administrator password and you do not have one, this
laptop is managed by somebody else and they have to do it. Use a cable
instead: it needs none of this.
```

The same text appears if you try to start a wifi handout, which is the one
moment we know for certain you are about to walk over to Settings and press a
switch that cannot work.

## Four deliberate choices in that message

**It gives you the exact words to type, not "enable the services".** The gap
between those two is the whole problem. Anybody who knew how to enable a
Windows service would never have needed the message.

**It names each one twice** — in plain words *and* as `icssvc` — so you can
recognise it on screen and also search for it, or read it to somebody on a
phone.

**It says the wifi card is fine, first.** That is the wrong conclusion people
reach, and it is the one that makes them give up.

**It says what to do when you are not allowed.** If the laptop belongs to a
school or an employer and you have no administrator password, that is a
perfectly reasonable thing for them to have done, and this does not tell you to
fight them. It tells you to use a cable, which needs none of this.

## It will not nag a healthy laptop

If nothing is switched off, none of this is printed. `doctor` stays the short
list of facts it has always been.

That matters: a screen that lectures everybody teaches people to skip it, and
the person who most needs the lines further down is exactly the person whose
laptop has the problem.

## One more thing it does not do

It does not read the words Windows prints. It reads a **number**.

Windows stores "switched off" as the number 4. That number is 4 whether the
laptop is set up in English, Arabic, French or Dari. The obvious tool for this
job prints `START_TYPE : 4 DISABLED` — and both of those words are translated
on a Windows installed in another language, so anything reading them would work
in London and quietly fail in Kabul.

This is the same reasoning that made an earlier release stop reading the words
`IPv4 Address` off a Windows network tool. It is worth writing down twice.

---

## Does the fix actually work? Yes. It was tried.

The advice used to be reasoning: those are the right services, so turning them
back on ought to work. That is not the same as knowing.

So it was done, on this laptop, and then undone again.

**Before** — Windows could not even build the thing that fills those boxes in.
That failure *is* the red bar; Settings has nothing to show, so it says the
only thing it knows.

**After typing the three lines** — a name, a password and a band appeared
immediately, and the hotspot switched **on**. The wifi stayed connected the
whole time, which matters if you are working over that same wifi.

**Then everything was put back to how it was**, and the failure came straight
back. That last step is what makes it an answer rather than a coincidence: undo
the change, and the fault returns.

One thing worth knowing that came out of it: **Internet Connection Sharing
never actually ran.** It only needs to be *allowed* to run, not started. So
there is nothing else to do after those three lines.

## Does this change anything on Linux?

**No.** Services being switched off in this particular way is not a thing that
exists there. The check returns nothing and prints nothing.

Linux users should stay on **0.9.5**, which remains current for them.
