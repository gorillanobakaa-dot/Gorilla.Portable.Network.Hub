## Reading

SECS is compression time. AIR_SECS is transmission time of the result.
Every SECS below 1.0 is already faster than the radio can drain it, so
for those rows the only column that matters is RATIO.

igzip shows MISSING because the 'isal' package is not installed. It was
included deliberately: the hypothesis is that hardware-accelerated DEFLATE
loses here, because it optimises SECS (already irrelevant) at the cost of
RATIO (the only thing that converts to saved airtime). gzip -1 at ratio
0.455 is the closest available proxy and it is already worse than
zstd -12 at 0.372. Install isal and re-run to settle it.
